# F7: Install dest fidelity: flattened path rewrite + plugin-scoped prune

## Goal
After `superskill install`, flattened skill dests resolve plugin-tree markdown links to sibling installed skills, native plugin dests keep their original repo-relative paths, and operators can optionally prune leftover dest skill dirs for the installing plugin only.
## Scope
- In:
  - Rewrite of plugin-tree relative markdown links (`../skills/<name>/…`, `plugins/<plugin>/skills/<name>/…`) when adapting commands and subagents onto the flattened skills floor
  - Target-class gate: rewrite applies only to dests that flatten to a skills root (codex, pi, opencode, hermes, antigravity-cli, antigravity-ide); never to native plugin-tree dests (claude, grok, omp)
  - Plugin-scoped `--prune` on `superskill install` that removes or replaces only dest skill dirs matching `<plugin>-*`
  - Docs: `docs/help/cmd_install.md` and the install flag table
- Out:
  - Copying or symlinking a skill's `references/` into each command-as-skill dest dir
  - Enabling rulesync `delete: true` on the shared skills root
  - Changing native plugin CLIs (claude / grok / omp) or mutating their dest plugin trees
  - Rewriting `plugin:name` colon references (already owned by `rewriteSkillReferences`)
  - Pruning dest dirs owned by other plugins
  - Source-side changes in consumer plugins (e.g. spur-new command markdown)
