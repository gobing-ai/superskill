# Review Signals

These are investigation prompts, not automatic penalties or proof of a defect. Verify the owning
source and report evidence, consequence, and a specific correction.

| Signal | Investigate |
|---|---|
| High grade presented as readiness | Were native behavior, task outcomes, dependencies, and relevant risks actually checked? |
| "Works everywhere" or invented flags | Does current help/source support the claimed host and operation? |
| Broad trigger list | Does actual discovery select this skill for near misses or miss intended requests? |
| Long body or growing references | Which loaded content affects a decision? Are useful guards or examples being hidden by premature pruning? |
| Repeated rules | Is there one authoritative owner, or do copies conflict or drift? |
| Mandatory interviews or approvals | Is material information or authorization really missing from the current session? |
| Repeated retries or indefinite review | Is there new evidence, a bounded recovery path, and a meaningful done condition? |
| Frozen frontmatter | Does it prevent correcting descriptions, stale versions, or invocation controls? |
| Security claims based on keywords | Are actual permissions and data flows inspected? Does a claimed sandbox exist? |
| External reads/writes or secret access | What purpose, destination, and authorization supports the operation? |
| Broken or omitted resources | Does the installed bundle include every file the workflow needs? |
| Evolution without evidence | Is there an instruction gap, requirement, or verified contract change worth addressing? |
| Better tests after a rewrite | Were acceptance criteria weakened or holdout answers leaked to the candidate? |
| A generated committee | Are independent agents available, authorized, and useful, or is role vocabulary being mistaken for mandatory delegation? |

Do not reject a skill solely for using negative wording, having few headings, being shorter than a
template, needing network access, or retaining a long useful example. Evaluate the actual task and
environment using [evaluation-framework.md](evaluation-framework.md); investigate executable and
authorization boundaries with [security.md](security.md).
